## 序言

欢迎你，陌生人！这是一个用 **Hugo + Stack 主题**搭的个人博客，平时写写技术笔记和闲言碎语。

把这里当作闲暇时偶尔推门进入的小馆，随便坐坐。

## 这座站是怎么搭的

| 部件 | 用的什么 |
|------|---------|
| 生成器 | Hugo（静态站点生成器） |
| 主题 | hugo-theme-stack |
| 托管 | GitHub Pages（免费） |
| 成本 | ¥0 |

## 怎么写新文章

在 `content/post/` 下新建一个文件夹和 `index.md`，写上 Markdown 就行，保存后浏览器里自动刷新。
