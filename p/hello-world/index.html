写文章的正确姿势

在 content/post/ 下新建一个文件夹（比如 my-second-post/），里面放一个 index.md：

---
title: "文章标题"
date: 2026-11-09T12:00:00+08:00
tags: ["标签"]
---

正文用 Markdown 写。

保存后 hugo server 会自动重新编译，浏览器刷新即可看到。

下一步（可选）

  • 想公开 → 推到 GitHub 开 GitHub Pages，零成本
  • 想要自定义域名 → 买个域名指过去，托管依然免费
